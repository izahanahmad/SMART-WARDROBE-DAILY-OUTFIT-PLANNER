# Requirements

## Functional requirements (what the system must DO)
1. The system shall allow users to create, view, update, and delete wardrobe items (e.g., uploading clothing photos, setting categories, colors, and seasons).   
2. The system shall generate daily outfit recommendations based on user preferences, current weather data, and planned occasions.   
3. The system shall allow users to schedule and save outfit combinations on a calendar planner.   
4. The system shall track item usage history to provide insights on least and most frequently worn clothing items.   
5. The system shall provide secure user authentication (sign-up, login, profile management) to keep wardrobe data private.

## Non-functional requirements (how the system must PERFORM)
1. The system shall load user wardrobe pages and generate outfit recommendations within 2 seconds under normal network conditions.   
2. The system shall ensure 99.9% uptime and render a fully responsive user interface across mobile and desktop browsers.   
3. The system shall securely store user credentials and wardrobe images using encrypted storage and HTTPS protocols.
